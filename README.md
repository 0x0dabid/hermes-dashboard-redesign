# hermes-dashboard-redesign

Nexus Command UI is a standalone frontend prototype for a redesigned Hermes Agent dashboard.

> This project is intentionally disconnected from real Hermes backend APIs and uses mock data only.

## Stack
- React + TypeScript + Vite
- Tailwind CSS
- Lucide React icons
- Recharts

## Setup
```bash
npm install
npm run dev
```

Then open the local URL shown in your terminal (usually `http://localhost:5173`).

## Included in this first deliverable
- Tailwind-enabled Vite React TypeScript setup
- Global app shell with futuristic Sidebar + TopBar
- Command Center page (implemented)
- Sessions page (implemented)
- Remaining pages scaffolded as placeholders
- Reusable UI components and centralized mock data
